# Code of conduct

We want InstaDeck to be a place where people can work on useful things without friction.

- Be respectful. Disagree with the idea, not the person.
- Assume good intent and ask before assuming otherwise.
- Keep feedback specific and actionable.
- No harassment, discrimination, personal attacks or publishing of other people's private information.

The maintainer may edit, hide or remove comments, issues and pull requests that break these rules, and may block repeat offenders. To report a problem, use a private security advisory on this repository or contact the maintainer through their GitHub profile.
